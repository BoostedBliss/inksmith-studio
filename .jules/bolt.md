## 2025-02-28 - [Performance] Debounce heavy sync operations and memoize SVG generation
**Learning:** Writing base64 data strings into `localStorage` synchronosly during dragging blocks the main thread. Also, continuously re-evaluating SVG generations in `ComicPanelItem.tsx` without memoization also blocks the main thread significantly.
**Action:** Always wrap heavy synchronous storage updates (especially containing image data/base64 strings) inside a debounced `setTimeout` within `useEffect`. Use `useMemo` in React components to avoid re-evaluating heavy synchronous code unnecessarily.
## 2025-03-01 - [Performance] Prevent unnecessary deep React re-renders in Comic Panels
**Learning:** Even though `ComicPanelItem` properly memoizes the expensive SVG `displayImage` generation using `useMemo` (which successfully bypasses recalculation for untouched panels since their `panel` object identity remains the same), the complex React components themselves (`ComicPanelItem`, `SpeechBubbleItem`, `SFXStickerItem`) still re-render because `App.tsx` passes unmemoized callback functions like `onUpdatePanel` and `onRegenerateImage`. This causes heavy but invisible DOM diffing overhead when typing or dragging elements.
**Action:** Use `React.memo` with custom equality functions on deeply nested complex components (like `ComicPanelItem` and its children) to explicitly ignore referentially unstable callback props and only compare the critical data objects (e.g. `prev.panel === next.panel`).
