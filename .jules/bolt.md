## 2024-11-08 - [React.memo and Latest Ref Pattern for Stable Callbacks]
**Learning:** React.memo is ineffective on complex child components like `ComicPanelItem` if the parent (`App.tsx`) passes down inline callbacks or functions recreated on every render. Because `useMemo` in `ComicPanelItem` correctly includes the `panel` object, any minor state change triggers re-evaluation of expensive functions like `generateThemedPanelArtwork` across *all* panels, severely impacting drag-and-drop and input performance. Attempting to cherry-pick `useMemo` dependencies is an anti-pattern that leads to stale closures.
**Action:** Pair `React.memo` on the child component with `useCallback` and the "latest ref pattern" in the parent component. By storing the frequently changing parent state (e.g., `currentComic`) in a `useRef` updated via `useEffect`, and using functional state updates (`setComics(prev => ...)`), the callbacks become referentially stable without stale closures. This isolates re-renders to only the modified child component.
